# 🧠 Second Brain — Émilie

Bienvenue dans le dépôt GitHub de mon **Second Brain** personnel propulsé par [Obsidian](https://obsidian.md).

Ce coffre numérique repose sur la méthode **P.A.R.A.** (*Projects, Areas, Resources, Archives*) issue de l'approche *Building a Second Brain* de Tiago Forte.

---

## 📁 Architecture du Coffre

```
Obsidian Vault/
├── 00 - Inbox/         # Boîte de capture rapide pour toutes les nouvelles idées / notes
├── 01 - Projects/      # Projets actifs avec objectifs et dates d'échéance
├── 02 - Areas/         # Domaines de responsabilité continus (Santé, Carrière, Finances, etc.)
├── 03 - Resources/     # Banque de connaissances, fiches de lecture, cheat sheets, guides
├── 04 - Archives/      # Projets terminés et notes inactives conservées en historique
├── _Templates/         # Modèles réutilisables (Projets, Daily, Ressources, Concepts)
├── Dashboard.md        # Tableau de bord principal avec liens interactifs
└── README.md           # Présentation du coffre
```

---

## 🔄 Synchronisation GitHub

Pour synchroniser automatiquement ce coffre directement depuis Obsidian sans ouvrir de terminal :
1. Dans Obsidian, va dans **Paramètres** ⚙️ > **Community plugins** (Plugins de la communauté).
2. Désactive le *Mode restreint* (Safe mode) et clique sur **Parcourir**.
3. Recherche et installe le plugin **Obsidian Git**.
4. Active-le, puis configure :
   - Sauvegarde automatique toutes les *X* minutes (ex: 15 min).
   - Push automatique au démarrage ou à la fermeture.
