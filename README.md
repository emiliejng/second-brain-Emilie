## 🔄 Synchronisation GitHub

Pour synchroniser automatiquement ce coffre directement depuis Obsidian :
1. Dans Obsidian, va dans **Paramètres** ⚙️ > **Community plugins**.
2. Active le plugin **Obsidian Git**.
3. Les commits et pushs s'exécutent automatiquement en arrière-plan.
